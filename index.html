Why do you study work and games?
Work and games are high-performance environments where humans are often operating at their peak. We also happen to spend a huge amount of our time on these activities! They involve mastery, communication, and training, and the data produced in these environments is deeply interesting.
What advice do you have for a student?
It's important to work on projects you enjoy. I started a few projects as a student that not only improved my coding ability but also brought me in contact with people who were nice enough to help me along the way. Find what you like and work on that -- it will come much easier.

Research

Research Areas

Human Performance

I study how people see, move, and make decisions while playing games and using computers. I use tracking data and experiments to measure performance and understand what changes it.

AI & Machine Learning

I design experiments and model training pipelines for computer-use agents, synthetic data generation, and AI-generated content detection.

Games, Esports & Sports

Boon  GitHub

pip install boon-deadlock

I built Boon to turn Deadlock replay files into match events, player state, and game stats. It provides Python bindings and a command-line interface and shares a Rust parsing core with Awpy. Boon has reached 85,000+ package downloads.

deadlock.nyc  Live site GitHub

I built deadlock.nyc to let players analyze Deadlock replays directly in their browser. It uses Boon compiled to WebAssembly to parse files locally and offers tick-level playback and on-device win probability predictions from a graph attention network. The site reaches 3,000+ monthly unique visitors.

Awpy  GitHub

pip install awpy

I created Awpy and previously led its maintainer team. The library parses Counter-Strike 2 replays in Rust and exposes match events, player state, and statistics through a Python API. It has reached 150,000+ downloads and 600+ GitHub stars.

Esports Trajectories and Actions (ESTA)  GitHub

git clone https://github.com/pnxenopoulos/esta

I used Awpy to create ESTA, an open dataset of player actions and trajectories from 1,558 professional Counter-Strike: Global Offensive replays. It contains 8.6 million player actions and 7.9 million game frames in about 4 GB of compressed JSON.

Litebook  GitHub

pip install litebook

Litebook is a limit order book implemented in Rust with a Python API.
